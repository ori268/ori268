# 안녕하세요, 정우진입니다 👋

AWS 기반 인프라를 IaC(Terraform)로 표준화하고, 배포·운영 안정성을 개선하는 **클라우드 인프라 엔지니어**를 지향합니다.
문제를 "증상 → 가설 → 검증"으로 쪼개 원인을 끝까지 추적하고 문서화하는 방식으로, 인프라 신뢰성을 스스로 책임지는 엔지니어로 성장하고 있습니다.
